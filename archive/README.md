# Archived BlueCloud projects and website material

This directory preserves the previous website's enterprise demos, portals, unrelated projects, assets and Tooldeck implementation. It is excluded from website deployment and desktop packaging. The active product source is in `apps/`; the active public website is at the repository root.

Archived components may contain obsolete claims or old integrations and should not be reused as current product information. Dependency caches remain ignored. No project was deleted from the original external Desktop repositories during consolidation.
