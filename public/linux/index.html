Install once. Keep creating.

Download the launcher AppImage, make it executable in your file manager, and open it. If your system does not support FUSE, run it with --appimage-extract-and-run.

Install your Cloud apps from the launcher. While it is open, it checks the signed Linux channel every 15 minutes and downloads updates for installed apps. Previous app versions remain available for rollback. Your documents and local libraries remain in your home folder.

Debian packages are available for compatible Debian and Ubuntu systems. Tooldeck’s protected-PDF tools also require qpdf from your distribution. These are early Linux releases; broad distribution and desktop compatibility are still being validated.
