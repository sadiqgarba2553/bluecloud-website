Coneic Installer Return Codes

Official installer exit code specification and documentation for the Coneic Windows Desktop Media Player, published by BlueCloud AI Technologies for Microsoft Partner Center Store submission and enterprise silent deployments.

Documentation URL: https://bluecloudai.online/coneic/installer-codes | Installer Technology: NSIS (Nullsoft Scriptable Install System) | Publisher: BlueCloud AI Technologies

1. Microsoft Partner Center — Installer Return Codes

When submitting a desktop application package (.exe) to Microsoft Partner Center, the installer exit codes must be defined so the Windows Store installer engine knows whether an installation succeeded, requires a restart, or failed.

Below is the exact mapping to enter in each field of the Microsoft Partner Center Installer parameters and return codes form:

Microsoft Store Field Exit Code Explanation & Behavior
Installation successful 0 Installation completed successfully (ERROR_SUCCESS). All application binaries, media codecs, shortcuts, and uninstall keys were written.
Installation already in progress 1618 Another setup process is actively running (ERROR_INSTALL_ALREADY_RUNNING). The installer mutex is held. The user must finish or terminate the existing installation.
Disk space is full 112 The target volume does not have sufficient free disk space to extract files (ERROR_DISK_FULL).
Reboot required 3010 Installation finished but a system restart is required (ERROR_SUCCESS_REBOOT_REQUIRED).
Network failure 12029 Network download or remote resource connection failed (ERROR_INTERNET_CANNOT_CONNECT).
Package rejected during installation 1625 Execution blocked by operating system security policies, missing administrative elevation (UAC), or antivirus restriction (ERROR_INSTALL_PACKAGE_REJECTED).
Installation cancelled by user 1602 The user aborted setup by clicking Cancel, pressing Escape, or closing the installer dialog before completion (ERROR_INSTALL_USEREXIT).
Application already exists 1638 An existing version is already installed (ERROR_PRODUCT_VERSION).

2. Complete NSIS Exit Code Specification

Coneic setup packages built with NSIS (Nullsoft Scriptable Install System) adhere to standard Windows process return codes:

Exit Code Status Standard Meaning
0 Success Normal execution completed with no errors.
1 User Abort Installation was aborted by user interaction (Cancel / Close).
2 Error / Abort Installation was aborted due to write errors, disk full, permission denied, or script error.
3010 Reboot Needed Setup succeeded but files are locked pending system reboot.

3. Silent Installation & Automation Parameters

For automated enterprise distribution via Microsoft Intune, SCCM, Winget, or PowerShell automation scripts:

Silent Install: ConeicSetup.exe /S
Silent Install to Custom Directory: ConeicSetup.exe /S /D=C:\Program Files\Coneic
Silent Uninstall: "C:\Program Files\Coneic\uninstall.exe" /S

Note: The /S command line parameter is case-sensitive in NSIS installers.
