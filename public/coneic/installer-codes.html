What are installer return codes? When an installer process finishes or encounters an error, it returns an integer exit code. Microsoft Partner Center, Intune, SCCM, Winget, and other deployment tools evaluate this code to determine whether installation succeeded, failed, was cancelled, or requires a reboot.

1. Microsoft Partner Center — Installer Return Codes

The following table maps every field in the Microsoft Partner Center "Installer parameters and return codes" form to the exact NSIS exit code value for Coneic.

Microsoft Store Field NSIS Exit Code Description
Installation successful 0 Installation has been successful. All files, registry entries, shortcuts, and uninstaller have been written without error.
Installation already in progress 2 Another installation is already in progress. The NSIS installer mutex is held by a concurrent setup process.
Disk space is full 2 The disk space is full. NSIS returns exit code 2 when a write or extraction operation fails due to insufficient storage.
Reboot required 3010 A restart is required to complete the install. Returned when locked files require replacement after reboot.
Network failure 2 Network-related failure. Coneic bundles all files locally, so network failures are not expected during normal installation.
Package rejected during installation 2 Package rejected due to a security policy. NSIS returns 2 when UAC elevation fails or antivirus blocks execution.
Installation cancelled by user 1 The user clicked Cancel, pressed Escape, or closed the installer window before completion.
Application already exists 0 Coneic performs an in-place upgrade when an existing version is detected, returning 0 on success.

2. Complete NSIS Exit Code Reference

Standard return values from every NSIS-compiled installer:

Exit Code Status Description
0 Success Normal execution completed. All files extracted, registry keys written, shortcuts created successfully.
1 User Abort Installation was cancelled by the user clicking Cancel or closing the installer window.
2 Script / System Abort Installation aborted by the installer script or OS. Covers extraction failures, CRC errors, insufficient disk, write denials, missing elevation, security blocks, and network failures.
3010 Reboot Required Installation succeeded but a system restart is required for locked files to be replaced.

3. Silent Installation Command

Install (silent): ConeicSetup.exe /S
Install to custom directory: ConeicSetup.exe /S /D=C:\Program Files\Coneic
Uninstall (silent): "C:\Program Files\Coneic\uninstall.exe" /S

The /S flag runs NSIS in fully silent mode. The /D= switch overrides the default directory. Both are case-sensitive.
