WiFi Master is an advanced Python-based automation wrapper for the aircrack-ng suite, designed to streamline wireless penetration testing from interface selection to password recovery within a unified, intuitive interface.

CORE FEATURES

Interface Discovery

Automatically detects and lists available wireless interfaces capable of monitor mode injection.

>> scanning_wireless_interfaces()

Monitor Mode Toggle

Seamlessly switch between managed and monitor modes with a single command.

>> enable_monitor_mode()

Network Scoping

Comprehensive network scanning with detailed target information and signal analysis.

>> scan_networks()

Handshake Capture

Advanced WPA/WPA2 handshake interception with deauthentication attack capabilities.

>> capture_handshake()

Password Cracking

Integrated cracking with support for multiple tools (aircrack-ng, hashcat, john, pyrit).

>> crack_password()

Automated Workflow

Complete step-by-step wizard for beginners and experts alike with interactive control.

>> automated_attack()

SYSTEM REQUIREMENTS

  • Linux-based operating system (Kali Linux recommended)
  • Python 3.x installed
  • Wireless adapter supporting monitor mode and packet injection
  • Root/sudo privileges
  • Aircrack-ng suite installed
  • At least 2GB RAM, 10GB free disk space
